zpm-cde is a package manager wrapper for APT, Flatpak, and Snap, made to ease package management.

Before install:
Make sure that all files of zpm-cde are in place.
Add executable permissions e.g. sudo chmod +x INST

Installation:
To install zpm-cde, run the INST file from the zpm-cde directory.
For automatic install, use the -y/--yes flag.
Display the help message with the --help/-h flag.

After installation:
Check all messages from the installation process.
If an error occurs, do not try to run zpm-cde.
Type zpm-cde --help in the terminal to check if the installation succeeded.


FILE LOCATIONS:

/opt/zpm-cde - MAIN DIRECTORY
/usr/bin - SYMLINK
